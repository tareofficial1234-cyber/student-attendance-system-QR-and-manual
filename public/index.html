How it works

  1. Admin creates sections and gives each section its own email/password.
  2. Add each student to the correct section; the system creates a unique PMM student ID and QR code.
  3. Use QR Scanner or Manual Attendance to record attendance.
  4. Each section account can see only its own students and attendance.
  5. Admin can see all sections, students, attendance and reports.

Add / Edit Student

Leave Student ID empty to automatically create a unique ID such as PMM-2026-00001. The QR code is generated from that student record. Only Admin can register or edit students.
